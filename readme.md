### CLI Todo App

Simple command-line todo application written in C++.

> Note: This tool currently targets Ubuntu-based Linux systems. Commands and
> install paths assume Ubuntu/Debian conventions (e.g., `/usr/local/bin`).

## Project structure

```text
cli-todo-app/
├── install.sh      # Install script for system-wide or user-local setup
├── mytodo.cpp      # C++ source for the CLI todo tool
├── readme.md       # This documentation
└── uninstall.sh    # Uninstall script 
```

## Prerequisites

- g++ (C++17 or newer recommended)
- bash (for running the install/uninstall scripts)

## Install

```bash
bash install.sh
```

If needed, make the script executable first:

```bash
chmod +x install.sh
```

## Uninstall

```bash
mytodo uninstall
```

## Usage

After installing or building, run:

```bash
mytodo --help
```
